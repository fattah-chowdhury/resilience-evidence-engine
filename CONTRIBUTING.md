# Contributing

Read docs/MAINTAINER_MANUAL.md and PROJECT_STATE.md before changing code. Keep changes small and preserve
valid completed reference artifacts. Add meaningful tests for changed behavior, including failure and
uncertainty cases. Run Ruff, affected tests and frozen reproduction when semantics could change.

Do not submit private records, secrets, copied full articles or unverified source licenses. Label synthetic
test evidence. Explain the problem, resulting behavior, validation and remaining limits in each change.
Public hosting is not yet configured; use the owner's chosen repository when one is established.
