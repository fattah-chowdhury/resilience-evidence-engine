# Synthetic CSV configuration exercise

All three records in fixture.csv are invented software tests under the repository MIT license.
One shared file drives mapped-column CSV, Bangladesh cyclone and Kenya flood configurations.
Run from the repository root:

```bash
ree run --config examples/custom_csv/project.yml
ree run --config examples/cyclone_monitoring/project.yml
ree run --config examples/custom_csv/kenya.yml
```

Mombasa is outside the tiny gazetteer and retains null geometry. These records are not real event evidence.
