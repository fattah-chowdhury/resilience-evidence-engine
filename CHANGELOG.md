# Changelog

## 0.2.0 — 2026-09-09 (experimental candidate)

Added contextual review exports, full-inventory/data validation, immutable acquisition resume, optional
public USGS cache, run comparison and explicit external adapter registration. Added configuration-only
flood/cyclone/Kenya/CSV examples and standard-library operational tests. Preserved distinct spatial
versions for provider updates, made unsupported languages fail clearly, streamed CSV/JSONL, and reduced
duplicate provenance payloads. Original reference files are unchanged; software-version-only provenance
tolerance is explicit. Release gates and current environment blockers are documented.


## 0.1.0 — 2026-09-07

Continued the preserved 0.1.0.dev0 Stage 0–1 checkpoint. Added a curated real-source offline demo,
generic local ingestion, place/time uncertainty, configurable rule extraction and assessment, copy-aware
linkage, immutable claim/event-link review, source discovery and bounded USGS transport, normalized/GIS
exports, field provenance and frozen reproduction. Expanded tests, installation/release audit and manuals.

Live external verification, online dependency advisory checks and desktop QGIS/R checks remain explicitly
blocked or unexecuted as detailed in release readiness. No stable v1.0 or public repository publication
is claimed. The historical checkpoint is preserved, not rewritten as if it contained these features.
